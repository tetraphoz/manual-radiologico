\chapter{Equipo para la Radiografía Industrial con Fuente Radiactiva}

Esta unidad de radiación gamma está diseñada para operar en forma remota y puede manejar hasta 100 Ci de iridio-192, lo que se reducen los tiempos de exposición a unos cuantos minutos. El iridio-192 es de los radioisótopos más versátiles y puede ser aplicado a secciones delgadas o gruesas (6.25 mm a 76 mm de espesor) para el acero o su equivalente para otros materiales).

El equipo básico consta de:
\begin{itemize}
    \item Cabezal blindado.
    \item Manipulador con indicador y cable de control.
    \item Ducto para la fuente radiactiva.
\end{itemize}

Y puede tener los accesorios siguientes:
\begin{itemize}
    \item Colimador de tungsteno (cono de 70°).
    \item Conjunto de abrazadera y trípode.
    \item Ducto para fuente (más corto).
\end{itemize}

\subsection*{Cabezal Blindado}

El cabezal blindado (figura 1) consiste de un recipiente cerrado de acero inoxidable, que contiene la cantidad suficiente de material aislante (uranio agotado) para reducir el nivel de radiación exterior. El blindaje está diseñado para aceptar con seguridad una fuente de 100 Ci de iridio-192, la cual está centrada en un tubo de titanio en forma de "S".
