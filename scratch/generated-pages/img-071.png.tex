\chapter{Procedimientos de Emergencia}

En las siguientes páginas se describen las instrucciones abreviadas de lo que debe de hacerse para atender a una emergencia. 

Procurar seguir fielmente cada uno de los pasos pero tenga presente que será la situación real la que determine las acciones más adecuadas.

En cada uno de los procedimientos se presupone que el personal involucrado cuenta con el siguiente material:
\begin{itemize}
    \item Pértiga para recuperación de Fuentes.
    \item Detector de Radiación.
    \item Detector con Alarma.
    \item Dosímetro de Lectura Directa.
    \item Dosímetro Termoluminiscente.
    \item Blindaje Media Caña.
    \item Blindaje de Emergencia.
\end{itemize}
