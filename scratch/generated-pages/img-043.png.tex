\section*{Organización y Responsabilidad del Departamento de Seguridad Radiológica}

Dado que la Seguridad Radiológica es un sistema de prácticas y criterios que involucran todas las actividades que se realizan con material radiactivo, las responsabilidades deben ser compartidas por todo el personal técnico y supervisor. El Departamento de Seguridad Radiológica es el encargado de vigilar que las indicaciones dadas por este manual se estén llevando a cabo tal y como se especifican.
