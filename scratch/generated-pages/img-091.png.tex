\subsection*{7.10.5}
\noindent Normalice el tratamiento de seguridad radiológica de estos casos, así como cualquier otro que se juzgue importante (por ejemplo, número de placas veladas, etc.).

% Start of section 7.10.6
\subsection*{7.10.6}
\noindent Realice los análisis bioquímicos siguientes:
\begin{itemize}
    \item Biometría hemática
    \item Espermatobioscopia
    \item Recuento de plaquetas
\end{itemize}

% Start of section 7.10.7
\subsection*{7.10.7}
\noindent No se exponga a ninguna fuente de radiación ionizante hasta tener una estimación de la dosis recibida.

% Start of section 7.10.8
\subsection*{7.10.8}
\noindent En caso de que personas del público hayan resultado sobreexpuestas, proceda de manera similar a 7.10.6 y 7.10.7.
