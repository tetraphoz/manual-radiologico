* Goal

Convert the BYN radiation-safety manual into a maintainable, reproducible LaTeX book project.

The finished project should have:

- one canonical LaTeX entry point;
- clean chapter/source files instead of page-by-page OCR fragments;
- source PDF/OCR material separated from generated and scratch files;
- figures stored in a predictable place;
- reproducible build commands;
- no credentials, editor cache, or LaTeX build products committed as source.

See [[file:todo.org][todo.org]] for the working plan and page-audit tracker.

* Quick start

If Nix is available:

#+begin_src sh
nix develop
#+end_src

Current canonical build:

#+begin_src sh
make pdf
# writes build/main.pdf from tex/main.tex
#+end_src

Other useful targets:

#+begin_src sh
make pdf
make clean
make cleanall
#+end_src

The same build is available directly through =latexmk=; project options live in [[file:latexmkrc][latexmkrc]]. All LaTeX auxiliary/build products are confined to =build/=.

#+begin_src sh
latexmk tex/main.tex
#+end_src

To recreate the extracted source drawings before building:

#+begin_src sh
scripts/extract_source_figures.sh
#+end_src

* Conversion workflow

For each page or section:

1. Open the source page image/PDF and the generated fragment.
2. Compare against =source/byn.txt= only as a secondary reference.
3. Correct OCR errors, spelling, accents, math, units, and punctuation.
4. Remove AI hallucinations or invented wording.
5. Convert page-local markup into semantic LaTeX: =\chapter=, =\section=, tables, figures, lists, equations.
6. Move reviewed content into the appropriate chapter file under =tex/chapters/=.
7. Build with =latexmk= and fix errors/warnings introduced by the change.
8. Mark the page/range as reviewed in [[file:todo.org][todo.org]]. Pages 001 and 003--008 are integrated under [[file:tex/frontmatter/][tex/frontmatter/]]; page 002 is blank in the source scan.

* LaTeX conventions

- Keep all source files UTF-8.
- Prefer real Spanish accents over TeX accent commands unless a package requires otherwise.
- Use one shared preamble in =tex/preamble.tex=.
- Add =\graphicspath{{assets/figures/}}= after moving figures.
- Distinguish source drawings from data graphs: preserve drawings as reviewed assets, but redraw graphs as LaTeX/TikZ so their labels and geometry remain editable.
- Use semantic structure rather than formatting-only commands where possible.
- Keep page-fragment files out of the final source tree unless they have been reviewed and integrated.
- Build with =-halt-on-error= once the current rough draft is clean enough.
